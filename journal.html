Project Setup

Week 1 · August 10–14

Objective

The primary objective for the first week was to establish the foundation for my Developer Engineering Notebook. This included setting up GitHub and creating the file and folder structure for the site.

Work Completed

  • Created the project repository.
  • Set up the project folders.

What I Learned

Light and Dark Mode

Entry 03

Light and Dark Mode

Week 3 · September 5–11

Objective

The primary objective for this week was to improve the usability and appearance of my Developer Engineering Notebook by adding a light and dark mode feature. I wanted users to be able to switch between different visual themes while also making sure their selected theme remained active when navigating between pages.

Work Completed

  • Added a light and dark mode toggle to the navigation.
  • Used JavaScript to switch between the two themes.
  • Used localStorage to save the user's selected theme.
  • Updated the CSS to create a separate light-mode design.
  • Tested the theme across multiple pages.
  • Fixed issues where the theme would reset when changing pages.
  • Adjusted the header, navigation, sections, and other elements to work with light mode.

What I Learned

I learned how JavaScript can be used to change the appearance of a website dynamically. I also learned how localStorage can save information in the browser so that a user's preferences can remain active when they move between different pages. This helped me understand how HTML, CSS, and JavaScript can work together to create a more interactive website.

Challenges

One of the biggest challenges was making the selected theme remain active after navigating to another page. The theme initially worked on one page but would reset when another page loaded. I had to use localStorage and make sure that every page loaded the same JavaScript file so the saved theme could be applied consistently.

Reflection

A feature is not finished just because it works once. It needs to work consistently throughout the entire application.

Adding light and dark mode showed me that developing a website involves more than just making individual features work. I also need to think about how different parts of the website interact with each other. Testing the feature across multiple pages helped me identify problems that I would not have noticed by only testing the home page.

Next Steps

  1. Improve the Projects page with project cards.
  2. Add JavaScript project filtering.
  3. Add another interactive feature to the Projects page.
  4. Continue improving the website's overall usability.

Entry 04

Setting up GitHub

Week 4 · September 13–19

Objective

The primary objective for this week was to set up GitHub for our Community Repair App. I wanted to create a repository where I could collaborate with others and track changes to our project.

Work Completed

  • Created a new GitHub repository for the Community Repair App.
  • Initialized the repository with a README file and a .gitignore file.
  • Connected the local development environment to the GitHub repository.
  • Pushed the initial codebase to the remote repository.
  • Set up branch protection rules to ensure code quality.
  • Configured continuous integration and deployment pipelines.

What I Learned

I learned how to use GitHub for version control and collaboration. I also learned how to initialize a repository, connect it to a local development environment, and push code to a remote repository. This helped me understand how to manage and track changes to a project over time.

Challenges

One of the biggest challenges was making the GitHub repository work consistently across all pages with all users. I had to ensure that everyone was using the same branch and that changes were being merged correctly.

Reflection

Build the basics first, then add features. A strong foundation is essential for a successful project.

Learning how to set up GitHub was a valuable experience that will help me in future group projects.

Next Steps

  1. Add Google Map to our app.
  2. Have a nice user interface.
  3. Create a nice logo for our app.
