AI Development Log

This page documents how I use AI during software development, including the problems I ask about, recommendations I receive, what I actually do, and what I learn from the process.

01 — AI Development Entry

Date: August 18, 2026

Goal

My goal was to learn how to implement photos into my website.

Prompt I Put

How to implement photos into my website and how to make them responsive.

What AI Recommended / Did

The AI recommended code that allowed my website to access an image from my images folder. It also explained how to change the size of the image.

What I Actually Did

I implemented the code that the AI recommended and it worked really well. I was able to add photos to my website.

Was the AI Right?

The AI was correct because the code it gave me worked without any issues and allowed me to add photos to my website and make them fit onto the screen.

What I Learned

I learned how to add photos to my website by adding photos in my images folder. I also learned how to edit the CSS to make the photos different sizes.

02 — AI Development Entry

Date: September 11, 2026

Goal

Learn how to add dark theme and light theme to my website.

Prompt I Put

Give me code that adds a dark theme and light theme to my website. Also explain how this code works.

What AI Recommended / Did

The AI generated code I could put at the bottom of CSS and generated JavaScript. It told me to add a button on my navigation bar.

What I Actually Did

I used the code AI provided and added a button to my navigation bar.

Was the AI Right?

After many errors, the AI finally explained why my JavaScript wasn't working. The revamped code it sent me was right and now light mode works on my website.

What I Learned

I learned that a lot of features can easily be added to the CSS and JavaScript. You can simply modify or add small parts to the website.
