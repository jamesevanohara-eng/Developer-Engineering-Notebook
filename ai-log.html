AI Development Log

This page documents how I use AI during software development, including the problems I ask about, recommendations I receive, and what I learn from the process.

01 — First AI Interaction

Date: August 18, 2026

Goal

My goal was to use AI to better understand how HTML works and learn how different features can be added to a website.

What I Asked AI

I asked AI for help with HTML, CSS styling, and adding images to my website. I also asked questions about how different parts of my website's code work together.

AI Recommendation

AI recommended code that allowed my website to access an image from my images folder. It also explained how to change the size of the image and provided CSS styling for the website.

What I Actually Did

I added an image to my images folder and then added HTML code to display it on my website. I also changed the image size and used the suggested CSS to style the website.

Was the AI Correct?

Yes. The recommendations worked correctly and helped me understand how images can be stored in a project folder and accessed using HTML.

What I Learned

I learned that AI can be useful for navigating unfamiliar HTML and CSS concepts. Instead of simply copying code, I can use AI to explain what the code does and learn how to apply it to my own projects.

My Takeaway

AI works best as a learning tool when I understand what the code does instead of blindly copying it.

Next AI Experiment

In future entries, I want to experiment with using AI to help debug code, improve my website, and learn JavaScript while still understanding and writing the final code myself.
